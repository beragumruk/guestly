# Commercial Use

Guestly is a commercial SaaS product.

This public repository exists so customers, partners, and technical reviewers can understand the product direction and engineering approach. It does not grant permission to use Guestly without paying for it.

## Businesses Must Use a Paid Plan

Hotels, boutique hotels, cafes, restaurants, hospitality groups, agencies, consultants, and other commercial operators must have a paid Guestly subscription or written commercial license before using Guestly in production.

Commercial use includes:

- running Guestly for a real business
- collecting live guest feedback
- using Guestly for hotel, cafe, restaurant, or hospitality operations
- deploying the product for staff, managers, owners, clients, or customers
- reselling or bundling Guestly with services
- operating a hosted copy, fork, derivative, or white-label version
- using the code to build a competing product

## Hosted Product

The intended commercial product is the hosted Guestly workspace:

```txt
https://app.getguestly.com
```

The hosted product may include services and infrastructure that are not included in this public repository, such as production authentication, billing, organization provisioning, hosted data stores, notification pipelines, and managed intelligence services.

## Public Repo Is Not a Free Deployment Package

The repository may run locally for review, but local/demo operability is not permission to self-host Guestly commercially.

If you want to use Guestly for your business, use the official hosted product or obtain written authorization from Guestly.

## Enforcement

Unauthorized production use, commercial hosting, resale, white-labeling, or derivative commercial use may violate Guestly's copyright, trade dress, trademark, and contractual rights.
